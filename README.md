# Pre-Entrega-Front-TT
Pre entrega de Front End Talento Tech

¡Bienvenido/a al repositorio de mi proyecto web! Este front corresponde a la **Pre-Entrega**, donde se consolida el progreso, la estructura semántica y los estilos aplicados hasta el momento, sirviendo como base fundamental para el Proyecto Integrador Final.

El sitio consiste en una página web funcional, interactiva y totalmente responsiva, orientada al e-commerce y la presentación de productos.

---

## Características y Requisitos Cumplidos

El proyecto fue desarrollado siguiendo estrictamente las consignas y rúbricas de la **Ruta de Avance**:

### 1. Estructura Semántica (HTML5)
* El sitio cuenta con una división clara y lógica utilizando las etiquetas semánticas principales: `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.

### 2. Formulario de Contacto Funcional
* Se diseñó e implementó un formulario de contacto responsivo con validación de campos para *Nombre*, *Correo electrónico*, *Asunto* y *Mensaje*.
* El procesamiento y envío de datos está integrado de forma 100% funcional utilizando **Formspree**.

### 3. Estilos y Diseño Visual (CSS3)
* Vinculación de una hoja de estilos externa (`styles.css`).
* Estilos personalizados aplicados al encabezado, pie de página y menús de navegación.
* Integración y renderizado de tipografías modernas mediante **Google Fonts**.
* Aplicación de propiedades de fondos (`background-color` / `background`) para mejorar la estética y el contraste visual de las secciones.

### 4. Layout Responsivo (Flexbox & Grid)
* **Sección "Productos":** Organizada de forma dinámica mediante tarjetas (*cards*) utilizando **Flexbox**.
* **Sección "Reseñas":** Estructurada estéticamente en forma de grilla mediante **CSS Grid**.
* **Sección "Contacto":** Adaptable a cualquier dispositivo móvil, tablet o de escritorio gracias al uso estratégico de **Media Queries**.

### 5. Contenido Multimedia y Navegación Interna
* Inclusión de elementos multimedia (imágenes/iconos) integrados correctamente en el flujo del sitio.
* Menú de navegación principal mediante listas desordenadas (`<ul>` y `<li>`) que simulan de manera óptima la navegación interna del sitio (Inicio, Productos, Contacto).

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** - Estructuración semántica.
* **CSS3** - Estilos, Flexbox, Grid y Media Queries.
* **Formspree** - Servicio backend para la recepción de mensajes del formulario.
* **Git & GitHub** - Control de versiones y alojamiento del código fuente.

"Vendo Pilchas" es una simulación de E-Commerce formada por la recopilación de los saberes aprendidos durante el curso de JavasScript Front End de Talento Tech.

La estétitca la página pretende ser ruidosa y juvenil, para eso se usan fuentes que recuerdan a los años 2000 y también colores brillantes.

El E-Commerce se enfoca en la venta de remeras gráficas con memes tendencia y productos relacionados con lo mismo.
